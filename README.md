# T1 — Unitree Go1

Проект команды 5-HT2A COLLECTIVE, в текущей версии реализован режим ping, который возвращает JSON для проверки запуска контейнера

## Сборка

Из папки проекта с DockerFile:

```
docker build --platform linux/amd64 -t 5ht2a-go1:local .
```

Для самой сборки понадобится интернет, для того чтобы скачать базовый образ и зависимости. Внутри образа используются Ubuntu 22.04, ROS 2 Humble и Cyclone DDS. Контейнер запускается от пользователя participant (UID 10001), что дает возможность использовать его без root-прав

## Проверка

```
python3 verify.py 5ht2a-go1:local
```

Скрипт проверяет архитектуру, запуск без root и ответ ping с отключённой сетью. При успехе появится offline ping OK
